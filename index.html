Ringkasan peternakan

Harga jual berdasarkan HPP

Simulasi memakai HPP operasional periode terpilih; HPP bulan berjalan dapat berubah ketika biaya aktual dimasukkan.

Catatan perhitungan

HPP = biaya produksi yang dibebankan pada periode ÷ telur layak jual yang dihasilkan dalam periode tersebut.

Biaya telur terjual mengikuti FIFO dari tanggal produksi. Pembelian pakan atau tray tidak otomatis menjadi biaya produksi.

Catat aktivitas

Setiap transaksi tersimpan ke Firebase. Harga dan tanggal transaksi tersimpan sesuai saat dicatat.

Panduan singkat

Urutan penggunaan: catat belanja pakan → pemakaian pakan → berat produksi telur → pengeluaran → penjualan dan jumlah tray ditukar. Stok awal dapat dimasukkan sebagai belanja bertanggal awal. Jika ada transaksi salah, hapus lalu catat ulang.

Laporan bulanan

Pengeluaran kas dan biaya produksi ditampilkan terpisah. Laba laporan ini adalah estimasi operasional sebelum biaya ayam/aset opsional dan pajak. Biaya periode masa depan yang belum dicatat dapat mengubah laporan historis.

Cadangan & pengaturan

Data aplikasi tersimpan di Cloud Firestore. Simpan file JSON secara berkala sebagai cadangan mandiri.

Impor mengganti seluruh data peternakan saat ini. Simpan cadangan dahulu.

Keamanan versi uji

Aplikasi tidak meminta login, tetapi menggunakan Firebase Authentication anonim di belakang layar. Aturan Firestore contoh memperbolehkan seluruh pengunjung anonim mengakses data peternakan yang sama. Jangan gunakan untuk data asli atau sebarkan URL sebelum autentikasi pemilik dan aturan akses per pengguna diterapkan.
